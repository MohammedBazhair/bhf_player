# BHF Player

تطبيق Flutter مخصص لاستيراد وتشغيل ملفات فيديو مشفرة بامتداد `.bhf` مع ربط التشغيل بهوية الجهاز والمقرر الدراسي، وتوفير تجربة تشغيل محمية مع إدارة محلية للبيانات.

---

## ما الذي يقدمه التطبيق؟

- **استيراد ملفات مشفرة**: اختيار ملفات الفيديو المشفرة (`.bhf`) من الجهاز.
- **فك تشفير آمن قبل التشغيل**: فك تشفير الملف على الجهاز فقط عند التحقق من الصلاحية.
- **ربط المحتوى بالمقرر والمعرّف**: الفيديو يعمل فقط إذا كان الجهاز/المستخدم مخولًا للمقرر.
- **مكتبة فيديوهات مفكوكة**: عرض الفيديوهات المفكوكة ضمن مقررات في شاشة مكتبة.
- **نسخ احتياطي واستعادة**: تصدير/استيراد قاعدة البيانات المحلية بصيغة مشفرة.
- **إعدادات الاستخدام**: وضع ليلي + تبديل اللغة (العربية/الإنجليزية) + معلومات التطبيق.

## آلية العمل بالتفصيل

### 1) مرحلة الإقلاع (Startup)

عند تشغيل التطبيق يتم تنفيذ التسلسل التالي:

1. تهيئة Flutter وإظهار Splash.
2. تهيئة النافذة/الشاشة و`media_kit`.
3. إنشاء/تهيئة قاعدة البيانات المحلية.
4. تسجيل الخدمات وحقن الاعتماديات عبر `GetIt`.
5. تهيئة ميزات مساندة (مثل الفيديو، النسخ الاحتياطي، فحص أمان الجهاز).
6. تنظيف الكاش عند الحاجة.
7. إخفاء Splash.

### 2) فحص أمان الجهاز قبل الدخول

قبل عرض الواجهة الرئيسية يتم تنفيذ فحص أمان الجهاز (مثل Root/Jailbreak/Emulator):

- إذا كان الجهاز **آمنًا**: يتم تحميل التطبيق بالكامل.
- إذا كان الجهاز **غير آمن**: تظهر شاشة تحذير `SecurityScreen` مع سبب المنع، ويغلق التطبيق بعد مهلة قصيرة.

> هذه الخطوة تمنع الوصول إلى المحتوى على بيئة غير موثوقة.

### 3) تهيئة التطبيق الرئيسي

عند نجاح الفحص:

- يتم تشغيل `MaterialApp` مع:
  - دعم تعدد اللغات (`ar`, `en`).
  - دعم المظهر الفاتح/الداكن.
  - مزود إشعارات داخلية (`Flushbar`).
- يتم تحميل `MultiBlocProvider` لحالات التطبيق الأساسية:
  - `DeviceIdCubit`
  - `ThemeCubit`
  - `LanguageCubit`
  - `CourseCubit`
  - `DecryptedVideoCubit`
  - `VideoDecryptionCubit`

### 4) تدفق الاستخدام الرئيسي (Import -> Decrypt -> Play)

1. **اختيار/إضافة مقرر**  
   المستخدم يحدد مقررًا (يحتوي سياسات/بيانات الوصول وكود التشفير).

2. **استيراد الملف المشفر**  
   اختيار ملف بامتداد `.bhf` من الجهاز أو استقباله مباشرة عبر مشاركة ملف للتطبيق (Android/iOS intents).

3. **التحقق من الصلاحية**  
   يتم التحقق من أن معرف المستخدم/الجهاز مخول للمقرر المحدد.

4. **فك التشفير**  
   - الملف يعالج على شكل أجزاء (`chunks`) لرفع الأداء.
   - يتم تنفيذ فك التشفير عبر Isolates متعددة.
   - يتم تحديث شريط التقدم أثناء المعالجة.

5. **استخراج معلومات الفيديو**  
   بعد نجاح فك التشفير، يتم قراءة بيانات الفيديو (مثل المدة) قبل التشغيل.

6. **التشغيل والإضافة للمكتبة**  
   يتم فتح مشغل الفيديو، وحفظ الفيديو المفكوك ضمن مكتبة المقرر.

### 5) قاعدة البيانات المحلية

التطبيق يعتمد قاعدة بيانات محلية لتخزين بيانات المقررات والمحتوى المرتبط بها.

- الإنشاء تلقائي عند أول تشغيل.
- دعم عمليات CRUD للمقررات.
- المكتبة تعتمد على حالة البيانات المحلية المزامنة مع BLoC.

### 6) النسخ الاحتياطي والاستعادة

- **Backup**:
  - إغلاق قاعدة البيانات مؤقتًا.
  - قراءة ملف القاعدة كـ bytes.
  - تشفيره AES.
  - حفظ الملف كنسخة احتياطية بامتداد `.bhf`.
  - إعادة فتح القاعدة.

- **Restore**:
  - اختيار ملف النسخة.
  - فك التشفير AES.
  - استبدال ملف القاعدة المحلي.
  - إعادة تهيئة القاعدة وإعادة تحميل البيانات.

### 7) ملاحظات حول الحماية

- فحص أمان الجهاز يحدث قبل دخول التطبيق.
- المحتوى لا يفتح إلا بعد التحقق من التفويض.
- المعالجة تتم محليًا على جهاز المستخدم.
- يوجد تكامل مع `clarity_flutter` للتتبع والتحليلات (بحسب إعدادات الوضع التطويري).


## المتطلبات والتشغيل

### المتطلبات

- Flutter SDK متوافق مع `Dart ^3.8.1`.
